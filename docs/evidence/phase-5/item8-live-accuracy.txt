Accuracy of the Hindi and Urdu live (near-live) models (Phase 5, item 8); numbers only; written by eval/item8_report.py.
machine: Legion (Intel(R) Core(TM) i9-14900HX); engine: wb-engine 0.1.0 (cuda, whisper.cpp v1.9.5 commit d1be6fde11ac tree e736b4c9a5be); device gpu:0; settings: near-live = greedy, no previous-text context, 15 s chunks; rolling = beam 5 with temperature fallback and previous-text context; language given (fixed); script-aware normalisation (eval/normalize.py); gate lock held for every run.
bar (PLAN section 6): near-live WER no more than 1.5 times the rolling WER of the ROLLING PICK (the lowest rolling WER of any model run here on the same clips), and RTF at or under 0.35. RTF = harness run time over audio time with one engine process per clip (engine start and model load included; this is why the short Kathbath clips look slower), 8 threads, Legion card only (it is not a laptop figure).
data: FLEURS hi and ur test (all clips), Kathbath hi and ur test (the Phase 3 lists eval/clips/phase3-kathbath-*.txt, 100 clips each). 'independent' is the harness's flag: Hinglish q8_0 is NOT independent on FLEURS hi (its starting checkpoint may have seen FLEURS), so only the Kathbath rows are clean accuracy evidence for it.
