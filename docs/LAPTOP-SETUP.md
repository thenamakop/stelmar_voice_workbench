# Setting up a room laptop

Do this once per laptop, with the installed app, before the event. Plug the laptop in, close other programs (browsers playing video, overlays, game launchers) and leave it alone while a check runs.

1. **Start the app and run the Quick Check** (System screen, "Run Quick Check"; about 3 to 8 minutes). The first launch asks for it. The check decides, on this laptop, which models and which device (processor, integrated graphics, discrete card) transcribe each language, and whether live text can be offered.
2. **Read the verdict** on the System screen.
   - **With a discrete graphics card** the Quick Check also measures the code-switching (Hinglish) model with a small model in front of it. English + Hindi and Hindi-only sessions use it while recording where it keeps up.
   - **Without a discrete card** (integrated graphics or the processor only) the Quick Check does **not** measure the Hinglish model: it cannot keep up with a recording on shared graphics, and the check has no time for more. The verdict says "was not measured" and why. English + Hindi and Hindi-only sessions then keep the ranked model of each language and are marked "best finished on a faster machine".
3. **On a laptop without a discrete card, run the Full Check once before the event** (System screen, "Run Full Check"; about 95 minutes on a low-end laptop). It measures the Hinglish model on every configuration, which is what lets the night pass decode English + Hindi and Hindi-only sessions with it when the night is long enough. Run it overnight or while you set up the room; do not use the laptop for anything else meanwhile.
4. Run the Quick Check again after any app update or driver change: the System screen says when the profile no longer matches the computer.
